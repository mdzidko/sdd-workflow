# Sdlc Review

Read the subject's original sources and pinned versions independently. Use selective search/read and actual operation evidence. Review only the assigned scope but consider dependency and multi-application consequences. Create a review-report with author/reviewer identity, subject references, outcome, evidence and actionable findings. Do not edit the author's deliverables. Do not confuse structural validation with semantic correctness or tool permission with business acceptance. Review-specific criteria are in your native role instructions. Any correction must be verified before its finding is resolved.

Invoke operations with `node scripts/workflow/run.mjs OPERATION --project PROJECT_ROOT`, passing JSON on stdin. Read the operation registry before assuming availability.
